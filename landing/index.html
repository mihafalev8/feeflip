How It Works

A fully automated lottery powered by PumpFun creator fees. No trust needed — just hold and win.

1
💸

Fees Collected

Every trade on your token generates creator fees. The bot automatically claims them via PumpPortal API.

2
🏦

Pool Grows

Claimed fees accumulate in the jackpot pool. The more trading activity, the bigger the prize.

3
🎲

Drawing Happens

At configurable intervals, a weighted random drawing selects a winner. More tokens = higher chance.

4
🏆

Winner Gets SOL

The entire jackpot is sent directly to the winner's wallet in SOL. Announced on Telegram.

Features

Everything you need for an automated, fair, and exciting token lottery

⚡

Lightning Fast

Uses PumpPortal Lightning API for instant fee claiming and SOL distribution. No delays.

⚖️

Weighted Fairness

Probability is proportional to token holdings. Bigger bags = bigger chances, but everyone can win.

📡

Real-Time Monitoring

WebSocket connection to PumpPortal tracks every trade in real-time. Always up to date.

🤖

Telegram Bot

Automated announcements for drawings, winners, and jackpot updates. Keep your community engaged.

🔧

Fully Configurable

Set your own intervals, minimum holdings, excluded wallets, and pool thresholds via .env file.

🛡️

Anti-Sybil

Minimum token balance filter and excluded wallet list prevent gaming the system.

Quick Start

Deploy your own FEEFLIP lottery in under 5 minutes

# Clone the repo
git clone https://github.com/mihafalev8/feeflip.git
cd feeflip

# Install dependencies
pip install -r requirements.txt

# Configure your token
cp .env.example .env
nano .env

# Launch the lottery bot
python feeflip.py
